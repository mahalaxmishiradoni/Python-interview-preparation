# Python Interview Questions and Answers

## 1. What is Python?

Python is a high-level, general-purpose programming language. It is designed for readable code and supports procedural, object-oriented, and functional programming. Python code is commonly run by an interpreter, and the language is used for scripting, web development, automation, data science, and many other tasks.

## 2. What are Python's main features?

- Readable syntax and significant indentation.
- Dynamic typing and automatic memory management.
- A large standard library and a broad package ecosystem.
- Support for multiple programming styles, including object-oriented and functional programming.
- Portability across Windows, macOS, and Linux.
- Interactive use through a REPL, as well as execution from script files.

## 3. What are the advantages and disadvantages of Python?

**Advantages:** Python is approachable, expressive, portable, and supported by extensive libraries and community resources. It is productive for prototyping, automation, web services, and data work.

**Disadvantages:** Pure Python can be slower than compiled languages for CPU-intensive workloads; dynamic typing can defer some errors until runtime; and the global interpreter lock in the standard CPython build can limit parallel execution of Python bytecode across threads. These trade-offs can often be addressed with profiling, native extensions, multiprocessing, or another implementation.

## 4. What Python versions are available?

Python has two major historical branches: Python 2 and Python 3. Python 2 reached end of life in 2020 and should not be used for new projects. Python 3 continues to receive feature releases (for example, 3.13 and 3.14) and maintenance releases. A project's supported versions depend on its dependencies and deployment environment.

## 5. What is the most stable Python version?

Use the latest maintenance release in the newest Python 3 feature series that your project's dependencies and hosting environment support. The exact latest patch release changes over time; check the Python downloads page before installing. For production, pin and test the version rather than assuming that the newest release is automatically compatible with every project.

## 6. What are the dependencies and software tools used with Python?

Python projects commonly use:

- **Interpreter:** CPython is the standard implementation; PyPy is an alternative implementation.
- **Package installer:** `pip` installs packages from package indexes.
- **Environment manager:** `venv` creates isolated environments; tools such as `uv`, Poetry, and Conda can also manage environments and dependencies.
- **Editors and IDEs:** Visual Studio Code, PyCharm, and other editors provide Python support.
- **Quality tools:** `pytest` for tests, `ruff` for linting and formatting, and `mypy` or Pyright for static type checking.

Project dependencies are usually recorded in a project configuration or a requirements file so they can be installed reproducibly.

## 7. What file extension is used for Python files?

Python source files use the `.py` extension. Compiled bytecode cache files commonly use `.pyc`; these are generated files, not the usual files developers edit.

## 8. Name ten prominent applications or products that use Python.

Python is used in parts of many products and services; it is rarely the only language in a large application. Well-known examples associated with Python include Instagram, YouTube, Dropbox, Reddit, Spotify, Pinterest, Quora, Disqus, Bitbucket, and the Blender 3D application. The language mix can change over time, and use of Python in a product does not mean the entire product is written in Python.

## 11. How does Python work internally?

In the standard CPython implementation, source code is parsed and compiled into bytecode. The Python virtual machine executes that bytecode. Imported modules may have bytecode cached in `__pycache__`, which can speed up later imports. Other Python implementations may use different internal execution strategies while following the language's behavior.

## 12. Explain Python's architecture.

At a high level, a CPython program passes through these parts:

1. **Source code:** `.py` files and imported modules.
2. **Front end:** tokenization and parsing check the source against Python's grammar and build an abstract syntax tree.
3. **Compiler:** the tree is compiled into code objects containing bytecode and metadata.
4. **Runtime and virtual machine:** the interpreter evaluates bytecode, manages frames and exceptions, and calls built-in operations.
5. **Object and memory systems:** values are Python objects; CPython primarily manages their lifetimes with reference counting and supplements it with cyclic garbage collection.
6. **C API and extensions:** native modules can connect Python code to C libraries and other lower-level functionality.

This describes CPython; alternative implementations can have different internals.

## 13. What is indentation in Python, and why does Python use it?

Indentation is leading whitespace at the start of a line. In Python, indentation groups statements into blocks, such as the body of a function, loop, or `if` statement:

```python
if temperature > 30:
	print("It's hot")
else:
	print("It's not hot")
```

Many languages mark blocks with braces; Python uses indentation as syntax so the structure is visible in the code. Colons introduce a block, and indentation defines its body. Semicolons are not required at the end of Python statements. Use consistent indentation, conventionally four spaces, and do not mix tabs and spaces in a block.

## 15. What are variables in Python, and how do they differ from variables in other languages?

A variable name refers to an object. Assignment binds a name to an object; it does not declare a fixed memory type for that name:

```python
answer = 42
answer = "forty-two"
```

Python is dynamically typed, so the object has a type and a name can later refer to an object of another type. In statically typed languages, a variable is often declared with a type that constrains which values it can hold. Python also supports optional type annotations, but they are generally checked by external tools rather than enforced at runtime.

## 16. What are Python's data types, and how do they compare with those in other backend languages?

Common built-in types include:

- Numeric: `int`, `float`, and `complex`.
- Boolean: `bool`.
- Text: `str`.
- Collections: `list`, `tuple`, `range`, `dict`, `set`, and `frozenset`.
- Binary data: `bytes`, `bytearray`, and `memoryview`.
- Null-like value: `None`, whose type is `NoneType`.

Python is dynamically typed and everything is an object. Its `list` and `dict` are flexible general-purpose collections; other languages may use statically typed arrays, maps, and generic collections. Python's `int` can grow to hold arbitrarily large integers (subject to available memory), unlike fixed-width integer types commonly used in many languages. Type annotations can describe expected values without changing this runtime model.

## 17. What are functions in Python? Explain the syntax with an example.

A function is a reusable block of code. `def` defines a function; parameters receive inputs, and `return` sends a result back to the caller. A function without an explicit `return` returns `None`.

```python
def calculate_total(price: float, quantity: int = 1) -> float:
	"""Return the total price for the requested quantity."""
	return price * quantity

total = calculate_total(12.5, quantity=3)
print(total)  # 37.5
```

Python functions are first-class objects: they can be assigned to variables, passed to other functions, and returned from functions. Annotations document intended types but do not normally enforce them at runtime.

## 18. What types of functions are there in Python? What are parameters and arguments?

Common function categories include:

- **Built-in functions**, such as `len()` and `print()`.
- **User-defined functions**, created with `def`.
- **Anonymous functions**, created with `lambda` for small expressions.
- **Generator functions**, which use `yield` to produce values lazily.
- **Methods**, which are functions defined on a class and accessed through an object or class.
- **Asynchronous functions**, declared with `async def` and used with `await`.

A **parameter** is a name in a function definition; an **argument** is the value supplied when calling it. For example, in `def greet(name):`, `name` is a parameter. In `greet("Ari")`, `"Ari"` is an argument. Python supports positional-only, positional-or-keyword, keyword-only, default, and variadic parameters (`*args` and `**kwargs`).

```python
def describe(name, greeting="Hello"):
	return f"{greeting}, {name}!"

describe("Ari")                         # positional argument
describe(name="Ari", greeting="Hi")    # keyword arguments
```
